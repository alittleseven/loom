# ADR-0002：模型路由降级链（修订 ADR-0001）

- 状态：已接受（2026-08-29）
- 决策人：Human Owner
- 关联：ADR-0001、v3.0 §5.3、`loom/edge/client/http.py`

## 决策

edge 层所有 LLM 调用走**固定降级链**（逐端点尝试，失败自动降级，全部耗尽 fail-closed 报错）：

| 序 | 端点 | 模型 | 线格式 |
|---|---|---|---|
| 1 | Opencode go `…/v1/chat/completions` | glm-5.3-flash | OpenAI chat |
| 2 | Opencode go `…/v1/chat/completions` | deepseek-v4-flash | OpenAI chat |
| 3 | Opencode go `…/v1/messages` | qwen3.8-flash | Anthropic messages |
| 4 | Ali Token Plan `…/compatible-mode/v1` | qwen3.8-flash | OpenAI chat |
| 5 | GLM `…/api/paas/v4` | glm-5.3-flash | OpenAI chat |

- ADR-0001 的"四档统一 GLM-5.3-Flash"语义保留：各档（render/review/scribe/small）的**模型 id 与档位路由表**随 P1b 盲测定版；P1a 全档走本链首位。
- 线格式双实现：`openai`（chat/completions）与 `anthropic`（messages）；序 3 是 Anthropic 格式。
- 重试语义：单端点内 JSON 解析失败重试 1 次；网络/HTTP 错误直接降级下一端点。
- 测试不依赖真实 Key：HTTPProvider 传输层可注入，cassette 录制回放（N4），CI 无 Key 可跑。

## 后果

- `.env.example` 与运行时 `.env` 变为三级五端点变量组（OCGO / ALI / GLM）。
- 成本记账按"实际命中端点"入 ledger（模型名逐次记录）。
- 宿主 agent（ZCode）仍不参与运行时调用——全部裸 API（§4.2 成本纪律）。
