# ADR-0001：edge 层模型路由基线采用 GLM-5.3-Flash

- 状态：已接受（2026-08-29）
- 决策人：Human Owner
- 关联：v3.0 方案 §5.3（模型路由与成本模型）、§4.6（盲测金标准集）

## 背景

edge 层需要四档模型路由（渲染档/评审档/scribe 档/小档）。P1a 需要一个可开发的初始路由配置；v3.0 §5.3 已把"便宜模型中文文笔"列为最大未验证假设（R2），并规定用盲测金标准集实测校准。

## 决策

1. **四档统一使用 GLM-5.3-Flash** 作为 P1a 开发基线（Human 拍板：模型切记使用 GLM-5.3-Flash）。
2. API 经智谱开放平台 OpenAI 兼容端点（`https://open.bigmodel.cn/api/paas/v4`）裸调用，不走宿主 agent（v3.0 §4.2 成本纪律）。
3. 最终分档路由表随 P1b 盲测金标准集（24 段匿名盲排）的"模型 × 场景"胜任矩阵定版；届时若 Flash 档文笔不达标，按 R2 降级预案转"便宜初稿 + 强模型润色"两段式。

## 后果

- `.env.example` 增加 `LOOM_LLM_BASE_URL` 与按档位模型名字段，缺省 `glm-5.3-flash`。
- P1a 的 LLMProvider 实现按此配置联通；盲测前所有档位等价，路由逻辑先以配置占位、不投入优化。
- 成本模型按 v3.0 §5.3 经济型档预估（≈¥0.15–0.25/章），上线后以 ledger 实测校准。
